# X 发帖增长技能

## 目标

为 X 账号 @1nhkjltx 生产**能让陌生用户愿意停留和转发**的内容，同时保留少量老粉互动内容。把「选题质量、真实素材、自然语言」置于机械追求条数之前。优先采用用户上传的最新账号数据，旧数据只作为历史基线。

## 工作流

### 1. 读取当天输入

- 识别用户目标：当天内容包、单条改写、热点搜集、账号复盘、图片创意。
- 若有最新 CSV 或帖子截图，先读取数据，核实发布时间及统计窗口；不能用旧数据冒充最新表现。
- 若需要热点/新闻/平台规则，先检索最新消息，确认事件发生时间、可靠来源与原始画面。事实不明时明确标注「待核实」。
- 遵守当轮用户指定的数量、长度、风格与受众。无指定时采用本技能默认配置。

### 2. 先找素材，后写文案

- 每天目标先找 50 个候选素材，再筛选最多 30 个合格题材；这是**候选产能，不是强制发布 30 条**。
- 来源可包括 X 热门内容、新闻机构、微博热搜、抖音及公开论坛。务必记录原始来源、日期、事件真伪和使用素材的授权状态。
- 避免照搬其他账号的表述、将网传段子写成真实新闻、无出处的爆料及诱导式虚假承诺。
- 优先筛选：真实意外画面、反常识细节、男女关系的具体矛盾、荒诞的现实冲突、亲自测试的技术发现。

### 3. 选题评分（内部，不必逐条向用户展示）

对候选内容分别按 0–5 分评估：

- 反差与新意（30%）：是否有具体、意料之外的事实或画面。
- 陌生人理解门槛（20%）：不认识该账号也能立刻看懂。
- 传播意愿（20%）：别人是否有理由转发给朋友。
- 素材可信度与可用性（20%）：可验证、可授权、可配图。
- 讨论潜力（10%）：是否存在真实分歧或轻松共鸣。

低于 3.5/5 的候选原则上淘汰；不为了凑数量而降质。

### 4. 历史题材配额（新数据不足时的候选池参考）

在需要 30 条候选稿且无新数据否定时：

| 题材 | 上限 |
|---|---:|
| 真实搞笑、反常识、意外画面 | 10 |
| 男女关系、关系边界、暧昧 | 7 |
| 社会荒诞、生活冲突 | 5 |
| X 圈子互动及日常 | 4 |
| 程序员、AI 真实经历 | 3 |
| 实验性新题材 | 1 |

以下比例仅是历史候选池，不是当前发布计划。当前策略以 `references/current-strategy.md` 为准。这是 2026-10-24～26 历史数据后提出的**7 天测试方案**，并非已证实的最优比例；及时根据新数据更新。详见 `references/account-insights.md`。

### 5. 文案规则

- 通常 20–80 个汉字；强画面素材优先 10–40 字。用户要求 3 行就限制为 3 行。
- 开头用最具体、最意外的事实或细节切入；不要固定使用「卧槽」「震惊」「你敢信」。
- 文案有完整信息：读者应当清楚发生了什么、为什么值得看；不能只有悬念而不交代。
- 语言口语化、有节奏、少 AI 腔、少模板化说教；少用套路反问和空泛口号。
- 保留独立视角，但不要编造人物对话、截图、经历或数字。
- 轻松搞笑、暧昧、争议题材要有具体情境；不重复已发过的「上门装系统」等老套桥段。
- 图片或视频有实质信息时优先保留原始可核实画面；可建议原创配图，但必须区分生成图和新闻纪实图。
- 若没有真实来源，不要把虚构内容冒充热点或真人事件。

### 6. 交付格式

**日常批量内容包**按传播潜力排序。每条给出：

1. 题材及一句话看点；
2. **可直接复制的最终帖子**（不是空泛的创意说明）；
3. 原始来源链接、日期（涉及真实新闻/热点时）；
4. 图片/视频建议和素材来源；
5. 状态：`可发布` / `待事实核实` / `待素材授权或制作`；
6. 为什么值得发：一句具体理由。

**单条优化**：默认先给一条最佳版本；用户要求备选开头才给多版本，不做冗长解释。

**热点分析**：必要时给出证据和具体做法，不能把问题抛回给读者作结。

### 7. 发布与合规

- 默认内容需要人工审核和发布；不要在未获授权前自动发布。
- 不协助伪造互动、垃圾刷屏或规避 X 的平台检测；符合平台当前规则。
- 不是所有素材都可直接转载；保留原出处，核实版权与使用许可。

### 8. 前天复核与动态更新

- 先读取 `references/daily-review.md` 的当前约定和 `references/current-strategy.md` 的有效策略，按北京时间08:00—次日08:00复核前天；同龄帖子表现与窗口新增曝光分别记账。
- 有真实同口径 24 小时数据时才比较；分开记录：浏览、转帖、引用、回复、主页访问、净增关注、非关注者曝光（如可得）。
- 关键维度是**陌生人传播与实际涨粉**；不要用互关圈的高回复数替代。
- 对每个题材比较：发帖数量、中位数浏览、300+ 浏览占比、转帖帖子比例、每千浏览的新增关注（数据充足时）。
- 分开评估纯文字、带图和视频，不以很小样本轻易作因果判断。
- 基于样本判断下一轮保留、优化或淘汰哪些内容；不要声称存在未经验证的 X 官方流量阈值。

## 快速触发示例

- 「使用 x-post-growth 技能，给我今天的 30 条候选帖子，必须附热点来源和图片建议。」
- 「把这个新闻改成适合 X 的三行文案，给三个不同开头。」
- 「分析这个 CSV，找出可以突破圈外传播的选题。」
- 「按昨天的数据调整今天的发帖方向。」
