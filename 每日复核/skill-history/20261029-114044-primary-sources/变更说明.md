# 原创来源边界修正

依据：用户明确要求独立找原始素材、参考对标写法、不再拿其他X账号成帖改配文；并要求每条实际附来源与配图。

原规则：榜单成帖发现→回溯→引用短评，配图可只给建议。

新规则：对标仅学选题与表达；独立搜机构、首发新闻、论文、创作者的一手素材；核验媒体与日期，交付原创正文、实际配图及必要署名。旧图与非现场物种照明示。撤回六条引用短评，旧稿保存withdrawn-posts.md。

观察期：内容来源边界是用户约束，立即生效，持续至用户更改；表达形式观察7天及同龄24h/72h数据。无本轮发布效果，不认定提高曝光。

撤回条件：来源边界仅用户明确更改时调整；试验表达若连续两个可比窗口中位浏览、转帖表现均走弱则重新选题，不能恢复搬用成帖。

校验：项目技能quick_validate通过；安装同步后比较三个变更文件的SHA256。交付四张源图均已查看，未生成虚构新闻图片。
